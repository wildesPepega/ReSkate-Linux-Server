Linux x64 build of the ReSkate dedicated server for **ReSkate 1.1.3** (network protocol 42).

### New: `map-mods` command
- Install custom maps from Thunderstore while the server runs: `map-mods add <Thunderstore link>` in the console, or `/map-mods add …` in chat for admins. The download runs in the background; the answer follows when it is done, and the map can be picked right away with `map <name>`.
- `map-mods` lists the installed map mods and the maps each one brings. `map-mods remove <map>` takes one out (by link, `Owner-Name` or map name). `map-mods update` fetches newer versions now.
- Added links are saved in `map_mods`. As before, only each map's `reskate-levels.json` is kept.
- A removed map also leaves `map_pool`. The map the server is on cannot be removed (change the map first); if one disappears at startup anyway, the server falls back to San Vansterdam instead of refusing to start.

### Changed
- Links from the Pterodactyl **Map Mods** variable (or `--map-mods`) are now installed **in addition to** `map_mods` and are no longer copied into the config file. Remove them in the panel.
  - On 1.1.3-1, the panel's links were copied into `map_mods`. If you remove a link in the panel and the map stays, also remove it with `map-mods remove <map>`.

### Update
Servers **install this on their own** once they are empty (or right away with `update`).

Needs glibc 2.31+.
