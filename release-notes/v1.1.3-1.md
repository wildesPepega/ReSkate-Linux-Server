Linux x64 build of the ReSkate dedicated server for **ReSkate 1.1.3** (network protocol 42).

### New: custom maps straight from Thunderstore
- List a map's Thunderstore link in `map_mods` (or `--map-mods`, or the new **Map Mods** variable of the Pterodactyl egg). At every start the server installs or updates it in `Mods/<owner>-<map>/`.
- Only the map's `reskate-levels.json` is kept. The server reads just that file out of the package (a few kilobytes), not the map itself.
- A newly installed map joins `map_pool` when the pool lists maps. A map taken off the list has its folder removed; folders you put in `Mods/` yourself are left alone.
- Pin a version with a link ending in `/v/<version>/`.
- See [installation.md](https://github.com/wildesPepega/ReSkate-Linux-Server/blob/main/docs/installation.md#maps-from-thunderstore).

### Update
Servers **install this on their own** once they are empty (or right away with `update`). For the Pterodactyl variable, import the new `egg-reskate.json` (attached).

Needs glibc 2.31+.
