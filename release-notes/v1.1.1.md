Linux x64 build of the ReSkate dedicated server for **ReSkate 1.1.1** (network protocol 41).

### Fixed
- **Server missing from the in-game server list.** ReSkate 1.1.1 only lists servers on network protocol 41; this build speaks it (#13).

### Changed (ported from ReSkate 1.1.1)
- Outfits carry whether a player hides their ReSkate tag and animated items, and how each of their marked cosmetics is coloured. The server relays them; outfits with flags or styles no game menu can make are refused.
- **Global bans**: players the ReSkate team has banned from multiplayer are turned away ("You are banned from ReSkate multiplayer."), also when they are already on. The list is read from `api.reskate.dev` at startup and every ten minutes (a minute after a failure); while it cannot be read, the bans already read hold. Set `"global_bans": false` in `ReSkateServer.json` to let them in; the server's own `bans` apply either way.

### Update
Servers on 1.0.8-1 or newer **install this on their own** once they are empty (or right away with `update`). Players need ReSkate 1.1.1. After the update the log should show `Global bans: N player(s) banned from ReSkate multiplayer cannot join.`

Needs glibc 2.31+.
