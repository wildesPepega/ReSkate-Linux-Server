Linux x64 build of the ReSkate dedicated server for **ReSkate 1.1.2** (network protocol 42).

### Fixed
- **Server missing from the in-game server list.** ReSkate 1.1.2 only lists servers on network protocol 42; this build speaks it.

### New (ported from ReSkate 1.1.2)
- **Map pool**: `"map_pool": ["San Vansterdam", "Isle of Grom", ...]` limits map votes to these maps (empty: every map). Admins can still change to any map. Console: `map-pool [add|remove <map>|clear]`.
- **Map rotation**: `"map_rotation_minutes": 30` moves to the next pool map every 30 minutes, with a minute's warning in chat. The clock waits while nobody is on and while a map vote runs. Console: `rotation [<minutes>|off]`.
- The map's name now travels with every map change, so players without a custom map's mod see which map they are missing.
- **Direct messages**: `msg <player> <text>`, `msg-party <player> <text>` and `msg-admins <text>` from the console or as an admin; players whisper each other with `/w <player> <message>`. Messages show as `[DM from ...]`.

### Update
Servers on 1.0.8-1 or newer **install this on their own** once they are empty (or right away with `update`). Players need ReSkate 1.1.2.

Needs glibc 2.31+.
