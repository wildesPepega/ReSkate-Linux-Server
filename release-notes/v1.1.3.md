Linux x64 build of the ReSkate dedicated server for **ReSkate 1.1.3** (network protocol 42).

### Changed (ported from ReSkate 1.1.3)
- **Server names**: ReSkate 1.1.3 only shows servers whose name is 1–64 letters, numbers, spaces and `- _ [ ] ( )`. The `name` command now refuses anything else.
  - A server whose configured name breaks the rule (e.g. `!`, `.`, `é`, emoji) **keeps running but is not listed**, and the log says so: rename it with `name <new name>`. (The Windows server refuses to start instead.)
- Global bans: the ban list's new `centrix` category is understood.

### Update
Servers on 1.0.8-1 or newer **install this on their own** once they are empty (or right away with `update`). Check the log afterwards for a line about the server name.

Needs glibc 2.31+.
