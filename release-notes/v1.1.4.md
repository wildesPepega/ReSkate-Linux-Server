Linux x64 build of the ReSkate dedicated server for **ReSkate 1.1.4** (network protocol 42, unchanged).

### Changed (ported from ReSkate 1.1.4)
- **Server names** may contain `/` (e.g. `EU/West 24/7`). Games older than 1.1.4 hide a server whose name has one.
- **`steam_token`** (new setting; on Pterodactyl the new **Steam Token** variable): a Steam game server login token from [steamcommunity.com/dev/managegameservers](https://steamcommunity.com/dev/managegameservers), App ID **3354750**, one per server.
  - With a token the server keeps the same Steam ID every start. That is also how the ReSkate team's list of official servers recognizes a server.
  - Empty (the default) signs in anonymously as before.
  - The ReSkate team can set the server browser to show **only servers with a token**. A listed server without one says so at startup, and again whenever that rule starts or stops hiding it. Players can always join with the code.
- Global bans: the backend's answer now also carries a `staff` category, official and blocked servers, and the token rule. The server reads and checks them; an answer with malformed lists still lifts no ban.

### Not ported
- Upstream's own Linux self-updater (from its release's `server_linux` tarball). This server keeps updating itself from this project's releases, as before.

### Update
Servers **install this on their own** once they are empty (or right away with `update`). Players need ReSkate 1.1.4 for `/` in server names; everything else works with 1.1.3 clients too. To keep your server listed if the token rule is switched on, set `steam_token` now (import the new `egg-reskate.json` for the panel variable).

Needs glibc 2.31+.
